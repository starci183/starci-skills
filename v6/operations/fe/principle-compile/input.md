# Principle compile input

Principle compile starts after source fit has closed package ownership and exposed only the remaining variable axes.

Provide one JSON value that validates against `input.schema.json`.

The input contains the approved layout reference, source-fit result and a closed list of open decisions. Each open decision names its target, concern, situation, allowed axis, relevant invariant and proof environment.

Allowed concerns are `composition`, `spacing-boundary`, `hierarchy`, `responsive-persistence` and `state-interaction`.

Do not provide a closed Grammar axis as an open decision. Principles do not choose packages, component exports, business-to-presentation mappings or generic complex-case anatomy. Product copy and domain meaning may justify upstream task weight but must not appear in the compiled product-neutral rule.
