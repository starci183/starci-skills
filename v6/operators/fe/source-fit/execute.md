# Execute source fit

## LOADS

| Alias | Target | Kind | Why |
|---|---|---|---|
| `@source-fit` | `fe.source-fit` | qdrant | choose reuse, declared extension, Block creation or blocking Grammar gap from effective contracts |

1. Run `node validate-input.mjs <input.json>` and verify every source-context artifact hash.
2. For each required owner, compare the exact Grammar selection with the source candidate's resolved effective contract.
3. Select `reuse` only when package/export identity, base hash, effective hash, slots, state inputs and closed invariants already match.
4. Select `extend` only when Grammar and the effective contract open the same axis, the extension policy admits the delta and the delta cannot alter anatomy, ownership or a closed invariant.
5. Select `create-block-or-above` only for Product Block, Layout or Page ownership and only after all contained lower-tier owners resolve.
6. Select `grammar-gap` for a missing leaf, branch, composite, exact export, neutral state mapping, complex-case ruling or allowed lower-tier axis. Draft a stable request obligation and stop local reconstruction.
7. Reject ambiguous verdicts, an AI-computed base-plus-delta merge, an implicit package substitute or a local wrapper that changes a closed owner.
8. Run `node validate-output.mjs <output.json>`. Emit nothing unless it passes; then route from the validated verdict set.
