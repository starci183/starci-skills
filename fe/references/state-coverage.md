# State coverage

Classify states by the owner that can change: block (loading/empty/populated/error/pending), page
(route/auth/orchestration), layout (responsive/navigation/overflow/theme), overlay
(closed/open/validation/submitting/success/error/dismiss/focus return). Cover zero, one, several
uneven items, pagination boundaries and data arriving after first paint. `not-applicable` requires
source evidence. Rendered claims require artifacts; a failed screenshot path is `OWED`, not proof.
