# FE intent

Intent explains which honest outcome should lead, for which audience state and with what evidence.
It informs Layout and Block choices; it never overrides contracts, accessibility or user autonomy.

| Router terms | Owner |
|---|---|
| CTA, primary action | [`call-to-action`](call-to-action/) |
| marketing frame, benefit, loss | [`value-framing`](value-framing/) |
| choice order, default, “chim mồi” | [`choice-architecture`](choice-architecture/) |
| proof, testimonial, credibility | [`trust-and-proof`](trust-and-proof/) |
| deadline, stock, urgency | [`urgency-and-scarcity`](urgency-and-scarcity/) |
| form effort, commitment, cancellation | [`commitment-and-friction`](commitment-and-friction/) |

Hard refusals: fake scarcity/proof, hidden price, ambiguous CTA, confirmshaming, forced consent and
obstructed cancellation. Machine context: [`intent.schema.json`](intent.schema.json).
