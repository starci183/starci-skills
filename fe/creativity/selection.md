# design selection

## Definition

Design selection chooses the strongest surviving direction after critique. It uses hard gates to
remove invalid concepts, then comparative judgement to choose the clearest product answer rather
than the most decorated one.

The deciding question: **which legal direction most clearly advances the page thesis across the
whole state matrix with the least unsupported complexity?**

## Rules

**SELECTION-1 · Apply hard gates before preference.**

A direction cannot win if it breaks canon, contradicts product data, obscures the primary CTA,
omits a required state or violates reference parity in migration mode. Visual appeal cannot offset
one of these failures.

**SELECTION-2 · Compare survivors on product dimensions.**

Judge CTA clarity, information hierarchy, task efficiency, state resilience, responsive coherence,
contract reuse and implementation reversibility. Originality matters only when it improves one of
those dimensions.

**SELECTION-3 · Prefer the smallest sufficient new vocabulary.**

An existing honest contract is stronger than a new one. A justified new contract is stronger than
misusing an existing one. The goal is neither zero additions nor maximal reuse; it is truthful
grammar.

**SELECTION-4 · Record why the winner won and why the nearest rival lost.**

This keeps the next implementation decision from reopening concept selection and gives future
critique the actual product tradeoff rather than a memory of visual preference.

## Forbidden

| Never | Why it is refused | Instead |
|---|---|---|
| Average incompatible directions together | The page loses the thesis each direction was testing | Choose one causal model and borrow only compatible details |
| Select the boldest by default | Difference is not user value | Choose the strongest product outcome |
| Select the easiest without naming the tradeoff | Effort silently becomes the design criterion | State what quality is being exchanged |
| Force reuse through a dishonest contract | The registry stops constraining children | Propose the smallest truthful addition |

## Examples

### A selection record
