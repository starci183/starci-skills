# Glossary — system terms

These English terms are the shared vocabulary between the teacher and the model: short,
unambiguous, and every skill in this system uses them exactly as defined here.

Never paraphrase them. Never invent synonyms for them.

| Term | Means | Used in |
|---|---|---|
| **axis** (plural: axes) | one of the 15 design axes (color, seam, frame, …) | everywhere |
| **canon is silent** | the axis applies, but no branch of its decision tree accepts this case | `research-when-silent` |
| **NOT COVERED** | verdict written when canon is silent — not covered yet | verdict rows |
| **our house scale** | the finite ladder of allowed values for an axis. Industry numbers must be **mapped onto** it, never imported beside it | every decision sheet |
| **grit** | a value that did not come from the library. Hardcoded color, hand-rolled layout, off-scale spacing | both lanes |
| **library gap** | the data shape or volume needs something the library does not define yet. Proposed as a widget, never enacted | both lanes |
| **anchor** | a measured fact that outranks reasoning: a real `src` line, a `getComputedStyle` value, a dated ruling | everywhere |
| **decision tree** | the ordered questions of an axis. Stop at the first YES | every decision sheet |
| **Forbidden** | the old per-axis ban list. Dissolved 2026-07-30 — each rule went to its enforcer: the type, a gate, `house-rules`, `judgement`, or `API-BACKLOG` | `docs/RULE-SCAN.md` |
| **Measure, don't look** | every verdict cites a number or a source line, never a screenshot | `house-rules` |
| **one example is not a rule** | promoting a case to a general rule needs two independent sources | `writing-canon` |
| **contract** | what a library entry publishes: role, API, states, skeleton, tokens. Not its implementation | `audit-block` |

## Writing rules for this system

- **Plain English throughout.** No Vietnamese anywhere in this system.
- **Tables over paragraphs.** A rule that fits a table row should never be a paragraph.
- **No emoji anywhere.**
- **Cite the date** when a rule comes from a real incident: `anchored 2026-07-29`.
- **State the negative.** Every skill description ends with what it is *not* for.
