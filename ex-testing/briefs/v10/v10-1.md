# v10-1 — gate fix: skip non-work payload yaml

`scripts/check-example-work.mjs` walks EVERY *.yaml in the tree and demands an `id` matching its path. But `assets/generation-receipts.yaml` and `assets/direction-check.yaml` are tool receipts (`schema: starci/generation-receipts@1`, `starci/direction-check@1`), not work records — 6 refusals are this misread.

Fix in `loadRecords`/walker: read the `schema:` field BEFORE treating a yaml as a record; if it doesn't start with `work/` (or the tree's declared record-schema prefixes), skip it as an artifact payload and count it as INFO `PAYLOAD_SKIPPED`. Don't whitelist filenames — the schema marker is the discriminator. Re-run gate: the 6 payload refusals must disappear; no other refusal may change. Report before/after counts.
