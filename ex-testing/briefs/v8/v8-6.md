# v8-6 — `scripts/check-work-artifacts.mjs` (declared bytes vs disk)

The gate verifies declarations, not bytes: `uat-flow` done needs `runs/<id>/videos/` non-empty — but a 0-byte file renamed `.webm` passes. A `ui-screen` declares `assets[].path` — the PNG may not exist at all. `accounts.yaml` is checked only `if existsSync` — a missing file silently passes. Your lane closes this: every declared artifact must be real bytes on disk.

Script: `scripts/check-work-artifacts.mjs`

Checks (each a named section + code):
- **ASSET_MISSING / ASSET_EMPTY**: every `assets[].path`, `asset.path`, `ui.assets[].path` declared in any record → file exists under the record dir, size > 0. REFUSE.
- **ASSET_MAGIC**: `.png` files start with `\x89PNG`, `.jpg/.jpeg` with `\xFF\xD8`, `.webm` with EBML (`\x1A\x45\xDF\xA3`), `.mp4` with `ftyp` box in first 12 bytes, `.gif` with `GIF8`. REFUSE on wrong signature — catches renamed fakes.
- **PROMPT_EMPTY**: every `*.prompt.txt` sibling of a generated asset → non-empty and references real input paths. REFUSE on empty/missing-when-declared.
- **RUN_MEDIA_FAKE**: uat `runs/<id>/videos/*` — each video ≥ ~10KB AND magic bytes match its extension; `screens/*.png` — PNG signature + non-trivial size. A settled run whose media are stubs → REFUSE `RUN_MEDIA_FAKE`.
- **RECEIPT_ORPHAN**: `generation-receipts.yaml` `toolOutputBasename` entries → the named file exists under the record's `assets/`; receipts naming bytes that aren't there → REFUSE.
- **RESOURCE_FILE_MISSING**: `uat-flow` `accounts:` file, `fixtures`, `environment` refs — files that don't exist must be REFUSE (the base gate's `if existsSync` gap is exactly the bug this fixes).
- **FEATURE_DONE_INCOMPLETE**: a `work/feature`/catalog-level `done` whose member records are `todo` or whose member ui/uat records lack their required artifact files → REFUSE. Parent cannot be done on children's unproven claims.
- **EVIDENCE_ARTIFACT_GHOST**: evidence.yaml entries naming run dirs / capture files / assertion outputs that don't exist on disk → REFUSE.

Verify against both real trees; paste counts. Note in report which checks fired on live data.
