The gate checks fields in isolation; this script checks records against EACH OTHER.

Script: `scripts/check-work-consistency.mjs`

Checks (each gets a named section + code):
- **AC_NAMING_ASYMMETRY**: `acceptanceCriteria: [short-names]` on fr/br should resolve to sibling `ac/<name>/` records under the same parent — v6-4 found `[is-idempotent, is-reversible]` short names that are never cross-checked, asymmetric with `ac.rule` which is. REFUSE when a resolvable ac dir exists but the name doesn't match; SUSPECT when no ac dir exists at all (may be intentional).
- **PROOF_COVERAGE_GAP**: a `done` fr/br should declare `requiresProof` covering what it claims — `unit.forEach: composes` present when composes exist, e2e for fr, etc. SUSPECT `PROOF_COVERAGE_THIN` when a done record has no requiresProof at all.
- **CONFLICT_WITHOUT_DECISION**: `conflictsWith` edges where neither side is resolved by a `work/policy-decision` — both records `done` while contradicting is refused-able ONLY when both are done (proven contradiction); warn otherwise. This catches the audit-retention vs stays-gone tension class.
- **PROVES_ASYMMETRY**: impl/uat `proves: [X]` but X's derived provenance would not include it — softer: report `proves` edges whose target is `todo` (already refused when source done; flag the todo-source case too as SUSPECT).

- **CATALOG_DIRTY**: `features/<f>/index.yaml` (work/feature node) exists per catalog entry and its `id`/`title` agree with the catalog's entry.
- **GAP_CLOSURE_LIES**: `work/gap` `state: done` where `closedBy` targets exist and are done (gate covers) — extend: gap done with NO closedBy at all → SUSPECT `GAP_CLOSED_BY_NOTHING`.
