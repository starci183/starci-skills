# v8-5 — `scripts/work-remap-path.mjs` (rename/refactor survival tool)

v6-4 failure-mode FM3: one directory rename (`src/modules/bussiness` is a typo waiting to be fixed) = N hand-edits across four denormalized field shapes (`br.module`, `impl.owners[].path`, `sds.owners[].path`, `fr.composes[].module`) + every covering evidence digest stale + unchecked `composes[].module` left dangling. Build the tool the audit asked for.

Script: `scripts/work-remap-path.mjs`

Interface:
```
node scripts/work-remap-path.mjs --tree <workRoot> --from <oldPathPrefix> --to <newPathPrefix> [--apply] [--with-evidence]
```

Behavior:
- Default is DRY-RUN: print every field that would change, grouped by record file, with old→new values. `--apply` performs the rewrite preserving yaml comments (edit via targeted string/AST-light rewrite — the codebase has `core/yaml.mjs`; check whether it round-trips comments; if it doesn't, do anchored text edits so comments survive).
- Rewrites ALL path-bearing field shapes: `owners[].path`, `module` (string or list), `composes[].module`, `surface.*` path fields if any, `inputRefs`, `evidence.codeDigest.files[].path`, plus prose-free path strings anywhere else a `/`-separated repo path appears as a full field value.
- `--with-evidence`: after rewriting, regenerate the affected records' `codeDigest.files[].path` entries (re-key hashes on module-relative paths is out of scope — instead mark each affected evidence.yaml `stale: true` with `staleReason: "path remap <from> -> <to>"` UNLESS the record has live assertions that still pass; simplest honest behavior: mark stale + let the evidence tool re-prove).
- Refuse to run when the `--to` path doesn't exist under the resolved repo root (prevents remapping into another fictional path).
- SAFETY: fleet v7 is live-editing these trees — DO NOT run `--apply` against the real trees. Test on a fixture copy (e.g. `xcopy` the todo tree to a temp dir, remap `src/modules/bussiness` → `src/modules/business`, show the diff). Report the fixture results.

Done → `done/v8-5.done` + report.
