## Part 1 — File upload (exup-4)

### Capability (`src/modules/integrations/upload/`)

| File | Role |
|---|---|
| `upload.contracts.ts` | `UploadStoragePort`, `VirusScanPort`, DTOs — swappable seams (S3/minio, real scanner later) |
| `upload-token.ts` | HMAC-SHA256 presigned token over `(uploadId, expiresAt)`, constant-time verify |
| `local-storage.adapter.ts` | Local FS adapter; storage keys minted server-side as `uploads/<uuid>`; containment-guarded (path escape → typed `UploadStorageUnavailableException`) |
| `noop-virus-scan.adapter.ts` | Explicit pass-through scanner; the contract is the seam, the stub is honest |
| `upload.service.ts` | Orchestration: validate → pending row → store → scan → ready; scan rejection deletes bytes and keeps the row pending |
| `upload.module.ts` / `upload.module-definition.ts` | Global register module, config-driven root dir + max bytes |

### HTTP door (`src/features/todo/http/upload/`)

`POST /uploads/intents` · `POST /uploads?filename=` (direct bytes) ·
`PUT /uploads/:uploadId/content` (`x-upload-token`) · `POST /uploads/:uploadId/attach` ·
`GET /uploads?taskId=` · `GET /uploads/:uploadId/content` · `DELETE /uploads/:uploadId`.

`express.raw` is applied by `UploadHttpModule.configure()` to exactly the two byte-bearing routes;
the global JSON parser owns the rest. Typed `UploadExceptionFilter` maps the `errors/upload/*`
exceptions (all `AbstractException` subclasses) to HTTP statuses.

## Part 2 — Observability (exup-6)

### Platform (`src/modules/platform/observability/`)

| File | Role |
|---|---|
| `request-context.ts` | AsyncLocalStorage request-id store |
| `observability.middleware.ts` | Honors inbound `x-request-id` else mints a UUID, echoes it on the response, feeds ALS; on finish emits one `http.request.completed` event via `WinstonService` (requestId/method/route/status/durationMs — **no** headers/bodies/query/auth) and records metrics |
| `metrics.service.ts` | `http_requests_total` counter + `http_request_duration_ms` summary labeled by method / **route template** / status; unmatched routes collapse to `unmatched`; label values escape `\`, `"`, newline |
| `observability.module.ts` | `configure()` applies the middleware `forRoutes("*")` — listed-as-provider is not applied; this was caught and fixed |

### Probe door (`src/features/todo/http/health/probes/`)

Placed under the health feature tree because the repo's REST-door lint rule requires controllers
under `src/features/**` with a `health` path segment — platform modules must not carry controllers.

- `GET /ready` — probes PostgreSQL; 503 via typed `PostgresUnavailableException` when down.
- `GET /metrics` — Prometheus text exposition. The dev-stack Prometheus config already scrapes
  `api:3001/metrics`.

`src/modules/platform/logging/log-events.ts` gained the `http.request.completed` event name.
