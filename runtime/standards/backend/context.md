# Backend standards router

## LOADS

None.

## Routes

| Need | Runtime target |
|---|---|
| Compile an accepted backend capability into files and dependencies | `runtime/standards/backend/patterns/context.md` |
| Judge an emitted backend lint finding | `runtime/standards/backend/gates/context.md` |
| Prove pattern, gate and published machine accountability | `runtime/standards/backend/rule-bindings/context.md` |
| Compile repository delivery assurance | `runtime/standards/backend/assurance/context.md` |

## Composition order

```text
accepted capability
  → patterns
  → approved exact files
  → implementation
  → gates
  → rule-binding parity
  → source proofs
  → assurance
```

No later stage may repair a missing earlier decision by guessing it.
