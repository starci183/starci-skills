# Trust-tree remnant

## LOADS

None.

## Stale signature

A target checkout resolved by the current route contains a nested `.claude/` left from an older Source.
This module never searches unrelated repositories.

## List evidence

Count files recursively and ask Git which are tracked. Report path, total files and tracked files. A shallow
listing is not evidence, and populated or tracked content is never described as safe to delete.

## Repair inventory

Two facts must both hold: every file is untracked by that target repository, and the directory contains
only empty paths or files no current law names. Otherwise return an owner decision; it may be real project
configuration or another Source.

## Apply

After exact destructive approval, remove only the verified remnant in its own pass and commit. Do not edit
or delete tracked content. Record `removed`, not `repaired`.

## Proof

Print recursive count before, approved absolute target and count after. The removal commit contains no
other pass.
