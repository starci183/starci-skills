# `architecture/alternatives` output

- `output.outcome`: one of `ready`.
- `output.resultRef`: exact inspectable visualize HTML comparison artifact.
- `output.directionCount`: three or four materially different rendered architecture directions.
- `output.visualPanelRefs`: one exact visible panel reference for every direction.
- `output.evidenceRefs`: exact supporting references.
- `output.findings`: bounded observable findings.
- `output.reason`: bounded explanation when work cannot complete, otherwise null.

## Contract fields

- `output.aiExecution`: Runtime-attested single fresh Sol execution provenance.
