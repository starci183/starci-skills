# Input

Bind exact curriculum and current-source evidence, the learner audience, requested editions, zero to four implementation tracks, and one brief destination.

## Contract fields

- `context.contextRefs`: Exact curriculum, style, and migration authority references.
- `context.sourceRefs`: Exact current lesson or source evidence references.
- `input.objectiveRef`: Exact bounded educational objective reference.
- `input.audience`: Learner profile whose prerequisites and outputs must be designed.
- `input.naturalLanguages`: Natural-language editions required from the later writer.
- `input.implementationLanguages`: Zero to four programming-language tracks to design as one behavioral contract.
- `input.briefTargetRef`: Bounded destination reference for the frozen teacher brief.
