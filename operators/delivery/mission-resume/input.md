# `delivery/mission-resume` input

Resume the approved product mission after an in-skill backend delivery. It joins the backend delivery proof with the original mission continuation identity and never reloads product or business bodies.

## JSON architecture

- `provided` carries the mission, impact and backend-proof refs.
- `loads` binds those exact session artifacts at runtime without loading semantic source bodies.
- `session` scopes every intermediate ref to the parent skill terminal.
