# `delivery/impact-classify` input

- `context.artifacts`: exact mission and route artifact bindings.
- `context.business`: exact published business-head binding.
- `context.knowledge`: one pinned delivery-impact law binding resolved by default search.
- `context.sourceMetadata`: metadata-only routed source heads; source contents stay unopened.
- `input.missionRef`: exact bounded mission reference.
- `input.businessHeadRef`: exact business-head reference.
- `input.routeReceiptSetRef`: exact verified workspace-route receipt set.
