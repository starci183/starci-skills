# interface.generate — brief

Follow operator.md; write its declared paths and your branch response/; replace the running response.json before exit. ? optional; * fallback. Context is limited to what request.json names.

## Done when

Done when, under mode apply, the `frontend-source-application` and its `changes` account for one commit on the session branch whose `writes` carry every declared path with both hashes and only values the `inventory` frozen beside the `frontend-presentation-resolution` and `resolved-tree` publishes, with a clean sweep and the committed tree equal to the resolved one, that tree realizing the direction the `frontend-direction-decision` selected over `candidates` served on `host`, printed, falsified and scored, with the surface class in the `ui-coverage` and the selected rendered PNG recorded as `selected-candidate-capture` and `outcome.primary`; or, under mode dry, the same with a null commit and an untouched checkout; or, when the direction declared a presentation delta of none, the same selected render evidence beside an empty owner map, no chosen rule and an empty inventory.

Primary output: `frontend-source-application`

`business-promise-authority`?, `backend-source-application`?, `architecture-decision`?, `frontend-direction-decision`?, `frontend-surface-audit`?, `library-source-application`?, `units`?, `findings`?, `knowledge-repair-receipt`?
