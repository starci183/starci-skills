# `fe/dominant-direction-generate` input

Consumes one structurally rejected finding batch, the frozen direct-owner ceiling, approved business
authority, and the nearest product-family signatures. It is never invoked for a request to compare
alternatives.

- `context.authorityRefs`: Frozen business, scope, family, and Grammar authority.
- `context.evidenceRefs`: Latest structural visual findings and runtime observations.
- `context.uiKnowledgeId`: StarCi UI knowledge binding.
- `input.targetRef`: One direct feature target being reconstructed.
- `input.findingBatchRef`: Structurally rejected visual finding batch.
- `input.ownerCeilingRef`: Frozen writable owner boundary.
- `input.familySignatureRefs`: Nearest sibling product-family signatures to reconcile.
