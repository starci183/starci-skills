# Execute `fe/direction-generate`

Generate three or four materially different frontend directions only when no dominant action exists.
Apply `knowledge/direction-visualization.md`. Produce an inspectable `visualize` HTML comparison that
renders every direction with realistic content, wide and constrained composition, and material
interaction/recovery states. A prose-only direction set is incomplete.

Use StarCi-native frontend authority from `knowledge/ui.md` and the routed project Grammar. Follow `AI-first -> Rules-first -> Grammar-last`. Return only this atomic result; never route internally. 

Before rendering, normalize every candidate through `knowledge/grammar/common/semantic-composition.md`
and validate its Grammar 7.4 decision manifest. Record every accepted and rejected candidate.
Rejected candidates must not appear in the visualize artifact or enter ranking. Fewer than three
accepted candidates is a Grammar gap and returns `blocked`; visual-only variants cannot pad the set.
