# `fe/direction-generate` output

- `output.outcome`: Typed result routed only by the parent Skill machine.
- `output.result`: This operator atomic product, including the exact repeated compiled request
  ref/fingerprint, one inspectable local visualize HTML artifact, the repeated mode, visually addressable directions, wide/compact/material-state refs,
  Grammar manifests, trade-offs, `requiresChoice`, and the exact compile-owned `grammarBinding`,
  `iconographyManifest`, `mediaManifest`, and `productFamilyEvidence`; or null when incomplete.
- `output.gaps`: Exact blockers or authority gaps.
- `output.evidenceRefs`: Exact evidence used.
- `output.handoff`: Always null; the generator never owns routing or cross-domain continuation.

`generated` requires the compiled request ref in exact evidence, one fresh Sol execution, and one inspectable local `.html` artifact registered in
the artifact set. `dominant` returns exactly one accepted direction with `requiresChoice=false`;
`alternatives` returns three or four, at least three material differences, and
`requiresChoice=true`. The parent may enter user-choice wait only for that true flag. `blocked` has a
null result and exact evidence/gaps;
`aiExecution` is null only when no call ran and retains fresh-Sol provenance when a post-call filter or
artifact effect failed. Prose-only directions are invalid.

## Contract fields

- `output.aiExecution`: Runtime-attested single fresh Sol execution provenance.
