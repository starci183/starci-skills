# `fe/grammar-convergence` output

- `output.outcome`: Legacy semantic result consumed only by the Skill machine.
- `output.result`: A pre-source `grammarBindingRef` that binds the law-valid layout, frozen semantic
  details, routed Grammar Core, packaged object/component contracts, visual DNA, and product-family benchmark evidence; or null when refused.
- `output.gaps`: Exact missing authority or evidence; empty when complete.
- `output.evidenceRefs`: Exact evidence used to produce the result.
- `output.proposalRefs`: Exact `proposal://...` records for reusable Grammar gaps awaiting the
  teacher's explicit approval; empty when no public Grammar addition is proposed. A proposal ref is
  evidence for the approval gate, never renderable Grammar authority.
