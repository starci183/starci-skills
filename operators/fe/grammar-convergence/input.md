# `fe/grammar-convergence` input

## Context

- `context.evidenceRefs`: Exact canonical evidence references available to this atomic job.
- `context.authorityRevision`: Exact approved authority revision binding this invocation.
- `context.routedGrammarRevision`: Exact routed Grammar revision compiled by this invocation.

## Input

- `input.targetRef`: The one target owned by this atomic invocation.
- `input.layoutCompilationRef`: Exact law-valid responsive layout.
- `input.uiLawBindingRef`: Mandatory UI-law binding preserved through Grammar compilation.
- `input.uiDetailBindingRef`: Law-governed destination, progress, and fact-hierarchy detail binding
  that Grammar must preserve.
- `input.grammarCoreRef`: Routed packaged Grammar Core identity.
- `input.packagedContractRefs`: Reusable object/component contracts selected from Grammar Core.
- `input.visualDnaRef`: Exact visual DNA applied by Grammar Core.
- `input.productFamilyRef` and `input.benchmarkRasterRefs`: Product-family identity and visual comparison evidence.
- `input.constraints`: Closed constraints that bound this job without routing it.
