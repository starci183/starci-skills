# `fe/ui-direction` output

- `output.outcome`: Legacy semantic result consumed only by the Skill machine.
- `output.result`: The atomic result with one inspectable visualize HTML comparison and three or four
  directions carrying wide, compact, material-state, trade-off, and visual-panel refs; or null when blocked.
- `output.gaps`: Exact missing authority or evidence; empty when complete.
- `output.evidenceRefs`: Exact evidence used to produce the result.
