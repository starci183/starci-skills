# Execute `fe/ui-detail-freeze`

## Step 1 — Convert approved design into anatomy

**Read:** one approved direction, flow, interaction-container plan, page set, and Grammar package. **Context:** current source supplies available contracts, not permission to change composition or replace an approved modal/drawer/page decision. **Session write:** breadcrumb decision, an ordered owned surface tree, and exact trigger/container ownership. **Stop:** if any visible region lacks an owner or component fit, or if an interaction-container decision is missing.

## Step 2 — Freeze composition behavior

**Read:** exact composition, Grammar, and interaction-container knowledge. **Context:** orchestration may independently check surface ownership, responsive behavior, overlays, and decoration. **Session write:** explicit merge, sticky, scroll, icon, separator, state, trigger, dismissal, focus-return, and responsive-container policies. **Stop:** on an implicit merge, unspecified decoration rule, container drift, or missing mobile transformation.

## Step 3 — Bind deterministic proof

**Read:** final detail model only. **Context:** baselines use fixed viewport, theme, state, and seed. **Session write:** visual refs and canonical `structureHash`. **Stop:** before code mutation or when a required screen/state lacks a baseline.
