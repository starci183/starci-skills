# Execute `fe/ui-detail-freeze`

## Step 1 — Convert approved design into anatomy

**Read:** one approved direction, flow, page set, and Grammar package. **Context:** current source supplies available contracts, not permission to change composition. **Session write:** breadcrumb decision and an ordered, owned surface tree. **Stop:** if any visible region lacks an owner or component fit.

## Step 2 — Freeze composition behavior

**Read:** exact composition and Grammar knowledge. **Context:** orchestration may independently check surface ownership, responsive behavior, and decoration. **Session write:** explicit merge, sticky, scroll, icon, separator, state, and responsive policies. **Stop:** on an implicit merge or unspecified decoration rule.

## Step 3 — Bind deterministic proof

**Read:** final detail model only. **Context:** baselines use fixed viewport, theme, state, and seed. **Session write:** visual refs and canonical `structureHash`. **Stop:** before code mutation or when a required screen/state lacks a baseline.
