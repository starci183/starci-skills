# `fe/iconography-resolve` input

- `context.evidenceRefs`: Exact evidence available to this atomic decision.
- `context.authorityRevision`: Exact approved authority revision binding the invocation.
- `input.targetRef`: One closed frontend target.
- `input.uiLawBindingRef`: Mandatory UI-law binding governing the visible roles.
- `input.semanticRoles`: Business-, UI-law-, or Grammar-authorized meanings that need glyphs.
- `input.approvedCatalogRefs`: Catalogs that must be searched before custom drawing is eligible.
- `input.constraints`: Closed visual or platform constraints; never routing instructions.
