# `fe/iconography-resolve` output

- `output.outcome`: `resolved` or `blocked`, routed only by the parent Skill.
- `output.result.iconographyManifestRef`: Immutable icon decision manifest consumed by later compilation and source mutation.
- `output.result.visualFamilyRef`: One family/optical-weight authority for the target visual layer.
- `output.result.decisions`: One semantic-role decision using an exact upstream Heroicon or an approved custom-SVG brief.
- `output.gaps`: Exact missing meaning or catalog evidence; empty when resolved.
- `output.evidenceRefs`: Exact evidence used.
