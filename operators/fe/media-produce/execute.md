# Execute `fe/media-produce`

Materialize exactly the frozen media decision after its mutation boundary is authorized. `none`
produces no file. `reuse` binds the approved asset without copying or redrawing it. `generate` uses
the frozen `media-brief://` to create one purpose-built bitmap at the authorized path and returns a
content-addressed raster plus generation provenance. Preserve the brief's product-family style,
subject, composition, palette role, safe crop, responsive treatment, alt intent and no-image fallback.

Do not use media to cover weak hierarchy, missing copy, dead space, or a defective layout. Do not
choose a new media mode, mutate application composition, invent text inside the image, or route. The
produced manifest returns to ordinary source composition and the complete responsive visual-review
matrix.
