# `fe/product-uat` output

## JSON architecture

The state is `passed`, `ux-ui-repair`, `repair`, or `blocked`. The report proves each journey step, exact Grammar object identity and anatomy, every user-visible semantic claim, state-marker mapping, prerequisite control gating, entitlement variants, and the business outcome. Hard UX/UI failures must route to `ux-ui-repair`; they may not disappear into generic repair. A passing rerun that names prior UX/UI requests emits `ux-ui-resolution-close-required`. A screenshot, matching surface count, plain state label, or existing container alone is never proof that the required object and content exist. Session intermediates purge at skill-terminal.
