# `fe/runtime-observe` output

- `output.outcome`: Typed result routed only by the parent Skill machine.
- `output.result`: This operator atomic product, or null when incomplete.
- `output.result.surfaceInventory`: Evidence-bound visible surface owners and their user purpose.
- `output.result.interactionInventory`: Every observed interaction with kind, owner, entry, outcome, and evidence.
- `output.result.responsiveStateInventory`: Exactly one observed wide, intermediate, and compact state.
- `output.gaps`: Exact blockers or authority gaps.
- `output.evidenceRefs`: Exact evidence used.
- `output.handoff`: Typed cross-domain continuation, only when the outcome requires it.
