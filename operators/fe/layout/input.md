# `fe/layout` input

## Context

- `context.evidenceRefs`: Exact canonical evidence references available to this atomic job.
- `context.authorityRevision`: Exact approved authority revision binding this invocation.

## Input

- `input.targetRef`: The one target owned by this atomic invocation.
- `input.directionRef`: Exact selected direction already validated by the law gate.
- `input.uiLawBindingRef`: Exact mandatory `knowledge/ui` law binding.
- `input.uiDetailBindingRef`: Exact law-governed destination, progress, and fact-hierarchy detail
  binding that the responsive geometry must preserve.
- `input.constraints`: Closed constraints that bound this job without routing it.
