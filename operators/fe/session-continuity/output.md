# `fe/session-continuity` output

Returns a verified authenticated lease on the same localhost origin and runtime generation, or an
exact blocker. A successful recovery resumes capture without restarting the mission.

- `output.outcome`: Typed result consumed only by the parent Skill machine.
- `output.result`: Verified authenticated replacement lease, or null when blocked.
- `output.gaps`: Exact recovery blockers.
- `output.evidenceRefs`: Exact lease and identity evidence consumed.
