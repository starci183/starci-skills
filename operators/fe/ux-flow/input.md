# `fe/ux-flow` input

`context.projectRoute` identifies the verified project backend Source. `context.businessHead` binds the exact approved business outcome. `context.journeyEvidence` supplies observed or approved journey facts. `context.uxLaws` supplies the exact continuity and state rules.

`input.targetOutcome` is the one approved result. `input.actor` is the one modeled user. `input.entryCondition` fixes the recognizable start. `input.surfaceSet` closes the surface boundary. `input.continuityRequirements` requires validation, failure, recovery, refresh, resume, and async coverage. No repository body, workflow state, or routing field belongs in this contract.
