# Execute `fe/render-capture`

Capture one deterministic raster evidence set from one validated `capture-preflight=ready` contract.
Do not mutate source, change the matrix, judge visual quality, call a reviewer, or choose another
operator.

Bind preflight, compiled request, registered source-apply RETURN, aggregate after-state, matrix,
partition, round, and capture/reuse partition identities unchanged. Reused partitions require their
frozen dependency proof; shared sentinels recapture. Source
or render-state drift blocks this invocation and requires a fresh one.

Capture the exact state-by-viewport matrix in `wide -> intermediate -> compact` order and every
applicable canonical probe in canonical lifecycle order. Preserve skeleton, loading, steady, empty,
recovery, result, scroll limits/restoration, zoom/restoration, overlay, focus, drag limit, content
stress, and breakpoint evidence under their own state identity. True non-applicability keeps a null
image and exact owner reason; tooling inability is not non-applicability.

Produce actual content-addressed raster files. Include one uncropped real host-context handoff raster
from the current user-visible browser surface without emulation, plus focused surface rasters with
enough parent and peer context to judge ownership. A distant host screenshot, DOM/geometry snapshot,
test, or source inspection cannot replace focused pixels. The sole final screenshot is the host
handoff raster captured after the latest mutation.

Freeze one retained raster-only blind-review packet ordered exactly as host artifact, render matrix,
then applicable probe rasters. Exclude source, DOM, tests, measurements, authority prose, producer
rationale, previous feedback, suspected defects, prior verdicts, and intended answers. Return only the
typed capture receipt; the parent Skill owns review or another capture invocation.
