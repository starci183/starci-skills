# s1 — kernel/store.mjs on the ledger (runtime 1.0.4)

## Method signatures (stable — s3/s6 code against these)

```js
const store=createStore({repoRoot,id});           // opens .starciwork/runtime.sqlite via openLedger; creates NO _local dir
store.schema | store.id | store.repoRoot          // unchanged
store.dir === null                                // no _local workflow dir exists anymore
store.ledger                                      // the openLedger handle ({db,transaction,now,file,path,close,...})
store.ledgerFile                                  // absolute path of .starciwork/runtime.sqlite
store.continuation                                // canonical <repo>/workflows/<id>.md projection path
store.paths.<anything>                            // DEPRECATED getter: throws `store-paths-removed:<name>` (read AND write)
store.reportPath(d) | .contractPath(op) | .checksPath(op)   // removed: throw `store-paths-removed:<name>`

store.appendEvent(event)                          // -> {seq,at,...event}; hash-chained INSERT INTO events
                                                  // entity_type 'workflow', entity_id=id, generation=bound gen or 0
store.readEvents({since=0}={})                    // -> [{seq,at,...payload}] of entity_type 'workflow', seq order
store.rotateEvents(generation)                    // -> {rotated:null,generation}; records one 'events-generation-closed' event (idempotent)
store.saveState(state)                            // -> state; snapshot row + events_head + workflows touch
store.loadState()                                 // -> latest bound state body; unbound: latest body any generation
store.bindJournal(handle,generation,{goalIdentity,state}={})  // handle = openLedger handle (was journal); seed = state ?? latest snapshot any generation
store.unbindJournal(handle=null)                  // unbinds all, or only if handle is the bound one
store.transition(state,{transitionId,event,apply})// replay of transitionId returns latest state, no second insert
store.acknowledgeRuntimeFile(file[,name[,mode]])  // ONLY for <repo>/workflows/**.md continuation projections; throws otherwise

store.writeReport({dispatchId,opId,attempt,generation,outcome,report,fromTerminal}) // upsert on (workflow,dispatch)
store.readReports()                               // -> [{...report,reportId,dispatchId,consumedAt,fromTerminal,createdAt}] by dispatch_id
store.writeContract({opId,attempt=1,dispatchId,markdown,context}) // upsert on (workflow,op,attempt)
store.readContract(opId,attempt=null)             // -> {opId,attempt,dispatchId,markdown,context,createdAt}|null; null attempt = latest
store.writeChecks({opId,attempt=1,checks})        // upsert on (workflow,op,attempt)
store.readChecks(opId,attempt=null)               // -> parsed checks|null; null attempt = latest

store.inbox.push({kind,key=null,payload=null})    // -> {id,kind,key,payload,status:'pending',createdAt}
store.inbox.pending()                             // -> [{id,kind,key,payload,status,disposition,createdAt,appliedAt}]
store.inbox.settle(id,status,disposition=null)    // -> bool; sets status/disposition_json/applied_at

store.signal.set(scope,key,{pid,token,value,ttl}) // scope = workflowId or '*'; ttl ms -> expires_at
store.signal.get(scope,key)                       // -> {scope,key,pid,token,value,at,expiresAt}|null (expired rows still returned)
store.signal.clear(scope,key)                     // -> bool

store.goal()                                      // -> {revision,identity,markdown,json,amendment,createdAt}|null (latest revision)
store.setGoal({markdown,json,amendment=null,identity=null}) // -> {revision,identity}; appends goals row, updates workflows.goal_identity

store.inputs.put({key,goalRevision,bytes,origin,mediaType=null}) // -> {ref,sha256}; upsert keyed (workflow,key)
store.inputs.get(key)                             // -> {key,goalRevision,sha256,size,mediaType,origin,bytes,createdAt,ref}|null
store.inputs.list()                               // -> [{key,goalRevision,sha256,size,mediaType,origin,createdAt,ref}] key order, no bytes
store.inputs.materialise(key,dir)                 // -> {file,ref,sha256}; digest-checked copy under dir, for a worker

store.exportTo(dir)                               // -> {dir,files}; runs checkpointLedger(handle) first (docs §3),
                                                  // writes state.json, events.jsonl (seq order),
                                                  // goal.md/goal.json, reports/<dispatch>.json, contracts/, checks/
store.close()                                     // closes the store's own ledger handle (not a bound one)

listWorkflows(repoRoot)                           // -> [{id,dir:null,state,updatedAt}] newest first; [] when no ledger file
workflowsRoot(repoRoot)                           // kept: migrator/exporter only
stateGoalIdentity, replaceStateSnapshot, slugify, newWorkflowId  // unchanged
```

Guards / named failures new in 1.0.4:

- `ledger-unmigrated:<id>` — createStore finds `_local/workflows/<id>` with no `workflows` row.
- `ledger-binding-mismatch:<id>` — bindJournal given a handle on a different file.
- `store-paths-removed:<name>` — any `paths.*` access/assignment, `reportPath`, `contractPath`, `checksPath`.
- `state.engine.journalFile`-without-`ledgerFile` handling (`predatesEngineSchema`, continuation) is s2/s3's side.

Event rows written by the store: `kind` = `event.event ?? event.kind ?? 'audit'`; `payload_json` = the whole
caller object (`JSON.stringify(event)`), so `readEvents` reproduces today's jsonl line exactly. Digest formula
matches ledger-db's private `digestOf`: `sha256((prevDigest??'') + eventId + kind + payloadJson + createdAt)`;
`state_snapshots.events_head` = `eventsHead(db,workflowId)` at every insert (save/transition/bind).
