# Back-end feature boundaries

## R29 feature shape

`BE_FEATURE_SHAPE` rejects files that their feature slot does not allow. Keep a feature's named module and `index.ts` at its root, application commands and handlers under `application/`, and protocol adapters under `transport/<protocol>/`. `BE_FEATURE_LAYOUT_INVALID` reports an adapter or another role in the wrong feature folder. `BE_APPLICATION_IMPORTS_TRANSPORT` rejects application imports that reach a transport adapter, including an indirect import chain. `BE_APPLICATION_TRANSPORT_FRAMEWORK` rejects a protocol framework imported into application code. In both editions, application code stays independent of the protocol that calls it.
