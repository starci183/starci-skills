# Capability error boundaries

## R38 error ownership

`BE_ERROR_HOME` keeps each capability's error family in its own
`errors/<capability>.error.ts` in both lite and full apps. The family exports a
capability-prefixed string code enum, an exhaustive `Record<Code, ErrorKind>`
mapping, and one empty subclass of `DomainError<Code>` from `platform/errors`.
Codes are unique across the repository. Throw the owning capability's domain
error rather than a built-in or framework exception; a domain capability
translates a platform failure before exposing it outward.

## R39 error masking

`BE_ERROR_MASKED` requires every API app in lite and full apps to register
exactly one `APP_FILTER` from `@nestjs/core`, using the filter declared by
`platform/errors` through `useClass`. Every `GraphQLModule.forRoot` or
`forRootAsync` registration passes the `formatError` exported by that same
owner. These registrations route undeclared failures through the shared masking
boundary before the client receives them. Missing filters and missing GraphQL
formatters are rejected.
