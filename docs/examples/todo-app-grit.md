# Todo-app grit ledger

The owner's method for finding what `.claude` gets wrong: build a real project (`examples/todo-app-backend`,
NestJS; `examples/todo-app-frontend`, Next.js) against the runtime's own checks, ops, schemas and kernel, and
record every place the runtime lied, blocked legitimate code, or had no home for a real need. This ledger
collects that grit from a dozen scattered lane reports into one table.

Every row below was checked against this checkout (branch `ex-grit`, based on `1aaa5f13`) and `git branch -a`.
A `fixed <sha>` status means `git show <sha> --stat` (or `git merge-base --is-ancestor <sha> main`) confirms
the commit is real and in the history this branch is based on. A `lane <name>` status means a worktree or
branch for that name exists but the cited fix does not — verified by `git log --oneline main..<branch>`. Two
items below (marked) were reproduced live in this session by re-running the actual scripts, not just by
reading commit messages.
