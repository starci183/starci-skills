# StarCi runbooks

Runbook biến một nhu cầu vận hành thành chuỗi lệnh lặp lại được, bám đúng repository sở hữu nó. Đây
không phải luật kiến trúc và không bao giờ chứa runtime value. Mỗi runbook phải nêu provider surface,
lệnh thật của repository, encrypted owner, tín hiệu verify, cách dừng an toàn và boundary rotate để
người chạy sau không phải dựng lại hệ thống bằng cách đọc source.

## Hợp đồng vận hành

Mọi runbook đi theo cùng thứ tự:

1. **Dùng khi** — tình huống chọn trang này.
2. **Trước khi chạy** — access, tool và source state phải có.
3. **Secrets** — chỉ ghi tên và encrypted owner, tuyệt đối không ghi value.
4. **Chạy** — command lấy từ wrapper thật của repository.
5. **Verify** — có kết quả quan sát được, không chỉ “command exit 0”.
6. **Dừng hoặc rollback** — thao tác nghịch đảo an toàn và dữ liệu nào được giữ.
7. **Rotate** — external record và local record nào phải đổi cùng nhau.
8. **Troubleshoot** — kiểm tra đầu tiên cho từng kiểu lỗi đã biết.
9. **Upstream** — tài liệu chính chủ khi UI/API provider có thể thay đổi.

Command chạy tại `D:\Repositories\starci-academy-backend` nếu trang không nói khác. Không gọi
`docker compose` trực tiếp cho dev stack: `npm run compose` phải render bridge port/credential từ
`metadata.json` và stack records trước.

## Fast path

Trên máy development mới, sau khi đã restore đúng SOPS identity:

```powershell
npm ci
npm run secret:gen -- dev
npm run sync
npm run compose
npm run start:dev
```

Lệnh đầu cài Husky. `secret:gen` chỉ tạo credential hạ tầng do repository sở hữu; nó không thể phát
minh key của provider bên thứ ba. `sync` decrypt record đã duyệt vào runtime path bị ignore và viết env
bridge. `compose` từ chối start nếu thiếu credential bắt buộc.

## Luật

1. Token value chỉ đi qua hidden prompt hoặc provider UI; không bao giờ nằm trong command argument.
2. Chỉ commit credential twin `*.enc`. Plaintext sibling là một run lỗi, không phải artifact.
3. Provider token và các projection GitHub/stack của nó phải rotate trong cùng một thay đổi.
4. `down -v` có tính phá hủy và không bao giờ là lệnh restart thường ngày.
5. Credential bên thứ ba chỉ được import hoặc replace, không do `secret:gen` tạo.
6. Link upstream trong runbook phải được kiểm tra lại trước mutation phía provider.
