# Accountability rule-binding backend

## LOADS

None.

## Record

Rule binding chứng minh chuỗi từ source shape đúng tới refusal rồi tới machine chạy được. Luật chi tiết
vẫn ở pattern và gate record; module này chỉ sở hữu accountability giữa các identity.

## Chain

```text
pattern situation code
  → gate situation identity
  → published @starci/eslint-canon-be rule hoặc external analyzer condition
  → executable proof
```

## Rules

1. Gate enforced không có machine identity đã publish thì parity fail.
2. Machine rule đã publish nhưng không có gate router thì parity fail.
3. Installed package không ship test source; machine-test proof là `unmeasured external` tới khi canon
   source checkout hoặc upstream CI có authority cung cấp evidence.
4. Situation documented-only chỉ hợp lệ khi law giải thích vì sao machine không quyết được.
5. Pattern/gate codes cố định; renumber cần consumer migration evidence.
6. Consumer cài canon và không vendor private rule copy.

## Stops

- Gate và package rule sets khác nhau.
- Rule không có law owner.
- Plan khai situation enforced nhưng binding vắng.
- Cần external analysis evidence nhưng không có authority.

## Proof

Chạy `node .claude/runtime/machines/rule-bindings/check.mjs --be` và test suite của canon đã publish. Sonar condition phía
provider vẫn là external evidence, không suy từ filesystem.

## Output

```text
pattern: <situation code>
gate: <gate identity>
machine: <published rule or analyzer condition>
proof: <executable evidence>
verdict: <bound | documented | missing | external>
```
