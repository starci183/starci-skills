None.

## Routes

Resolve the selected physical skill through `runtime/orchestration/profiles.json`, then load exactly one phase-map record.

| Map | Selected skills | Target |
|---|---|---|
| Frontend design | Layout, Block and Layout Refactor | `runtime/orchestration/frontend/en.md` |
| Capability pipelines | Every other StarCi capability | `runtime/orchestration/capabilities/en.md` |

Absence from the machine registry is a stop. A skill does not fall back to an approximate map.
