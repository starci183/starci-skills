# Analyze frontend mission

Compile and validate the complete frozen mission `scope` against `scope.yaml`, then validate one
intent, objective, target hints, authority refs, and optional exact resume receipt. Require exactly
one `frontend.ux-ui.change-level` dimension, an identical `uxUiChangeLevel` projection, and a
compatible `directionMode` and typed `directionEvidence`. Approved reconstruct/new reuse requires
the exact direction identity, content fingerprint, and direction-specific approval ref; reject an
empty authority list or a generic authority ref. When any
material scope dimension is unresolved, ask one focused boundary question before entering the
machine. A new mission starts at `request-compile`; a correlated receipt resumes its exact owned state without
re-analysis.
