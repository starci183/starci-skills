# Execute

Follow `machine.json`. The parent Skill routes; each operator performs one atomic job.

The normal sequence is `brainstorm -> write -> image -> code -> e2e -> review`. An approved review completes the mission. A typed revision returns to the named owner: concept to brainstorm, prose to write, visual to image, implementation to code, or executable behavior to E2E. Re-run every downstream proof invalidated by the fix. Stop only at a terminal state or a genuine authority/evidence dead end.
