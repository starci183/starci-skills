# starci-self-upgrade

Own one runtime-improvement boundary: turn reproducible workflow evidence into a measured causal
record, the smallest runtime-owner repair, and fresh regression proof. Select this Skill when the
requested object is StarCi's routing, Skill/operator behavior, speed, token use, step count, or result
quality. Do not select it merely because AI or a Skill participated in ordinary product work.

`calibrate` may write only under `.claude/upgrades/` and must not change product source or existing
runtime owners. `upgrade` requires explicit approval and write roots limited to the smallest proven
`.claude` owners. Preserve product worktrees as read-only fixtures unless the user separately
authorizes product delivery.

For live comparison, use [multi-task supervision](references/multi-task-supervision.md). The Skill may
launch two independent Codex tasks under separately frozen product authority and communicate with
them as a supervisor. A third task is legal only when the user explicitly supplies a third fixture or
when asymmetric/inconclusive results require a discriminator. The supervisor never edits actor
product source, merges their contexts, or issues their product verdicts.

Use the user's benchmark as an outcome-quality reference, not permission to copy its implementation.
Correct orchestration with an incorrect or unstable output is a failed mission. Observe the output
first, then audit the exact objective/scope, inputs, prompts, state machine, execute logic, knowledge,
Grammar/UI when applicable, validators, output contract, tools/models, and proof before naming the
smallest owner. Read [the output-correctness loop](references/output-correctness-loop.md) for this
diagnostic and retry contract.

Record measured or explicitly unavailable efficiency metrics, one accountable causal record, and
evidence-backed ADD/CHANGE/REMOVE dispositions. After repair, run the same acceptance contract from
fresh evidence until it passes twice consecutively. A repeated fingerprint, three failed repair
attempts, missing layer evidence, or any wrong output blocks; it never degrades into `complete`.
