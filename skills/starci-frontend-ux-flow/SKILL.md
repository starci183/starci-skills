# StarCi frontend UX flow

Turn one approved visual direction into a complete task flow. Model only relevant transitions, but never omit escape, recovery, or reversible navigation for multi-item work. Then compare page, modal, drawer, popover, and inline placement for every meaningful interaction; record one selection, four rejections, behavior, focus return, and mobile transformation. New persistence or backend behavior remains a typed hypothesis and routes separately.
