# starci-canon-first — why this exists

The roster is a set of narrow verbs — review, design, consolidate, build, sync, audit, register. That
narrowness is deliberate: it makes auto-trigger precise, each skill firing on its own lane and fenced
off from the others. But precision leaves a gap. A real request that names an *outcome* without a
*verb* — "make this page better", "tối ưu chỗ này", "clean this up" — matches no lane cleanly, and the
worst outcome is to force it into the nearest specialist, or to answer it ungrounded.

This skill is that gap's floor. It does one thing: **read the canon that governs the work before
touching it**, then either hand the now-clear verb to the skill that owns it, or do the work here,
grounded in the rules rather than around them.

It is written to LOSE every contest with a specific skill — the description names itself a last resort
and defers to each lane by name. `test.mjs` guards that stance, because a catch-all that stops
deferring stops being safe: it would start stealing triggers from the very lanes it exists to back up.
