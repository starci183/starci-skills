# Standards router

## LOADS

None.

## Record

Standards answer what accepted source must look like and how existing source is judged. They do not
orchestrate work, mutate providers or store session state.

## Routes

| Scope | Runtime target |
|---|---|
| Backend architecture, gates, rule bindings and assurance | `standards/backend/context.md` |
| Frontend design/source, gates, rule bindings and assurance | `standards/frontend/context.md` |
| Shared naming, type, maintainability and secret concerns | the matching role module until a genuinely role-neutral law exists |

## Rules

1. Select role after workspace verification.
2. Pattern emits the correct source shape; gate refuses existing evidence; machine enforces the gate.
3. One law has one authority. Routers point to it and never paraphrase it.
4. A role-neutral module exists only when FE and BE have identical inputs, outputs and refusal evidence.
