# Direction quality before proof

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.ui.direction-quality` |
| Operators | frontend direction, implementation, repair, and proof routing |
| Search tags | `first glance, direction score, brainstorm, business supplement, backend facts, quality threshold` |
| Dependencies | approved user outcome; `fe.ui.hierarchy`; `fe.ui.ownership-composition`; routed Grammar Core and product DNA |

Before the expensive capture matrix, judge one fresh, durably persisted representative raster as a
user would encounter the product. The raster must name the frozen acceptance, latest source
fingerprint, requested business state, local artifact identity, and fresh isolated reviewer execution.
An inline screenshot, producer narration, reconstructed score, recovery/error state standing in for a
ready-state outcome, or a raster without a durable artifact receipt cannot pass this screen. Score
exactly six dimensions from zero to ten: composition, hierarchy,
density/empty-space, product-family DNA, content/media purpose, and action clarity. The overall score
is the floored arithmetic mean. Only `9` or `10` may advance.

A result below `9` invalidates the current direction, not the approved business outcome. It consumes
no visual repair round and must not be dressed up as proof of a dead end. Brainstorm and render a
materially stronger direction. Do not use image generation to conceal weak hierarchy, missing
content, or purposeless space.

After two failed direction attempts, a third sub-9 result must classify the smallest missing
authority instead of repeating the same render loop. If the approved outcome lacks content, user
value, task framing, or media purpose, call Business to supplement or adjust only that missing input.
If live facts, persistence, permissions, or media fields are missing, call Backend. Preserve the
approved outcome and all unaffected authority; never replace the business merely to make the page
easier to compose.

This is a fast direction screen, not the final visual verdict. Passing it does not waive the complete
capture-preflight, render-state matrix, adversarial probes, or blind visual-fidelity review.
