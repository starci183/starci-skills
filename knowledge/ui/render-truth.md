# Render truth, not invented meaning

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.ui.render-truth` |
| Operators | frontend decision, implementation, review, and proof |
| Search tags | `truth, state, glyph, tone, semantic color, status, authority` |
| Dependencies | `fe.ui`; approved Behavior/business/backend authority; routed Grammar |

UI renders approved neutral facts and reachable states. It must not manufacture product truth,
authorization, trust, progress, success, urgency, or recovery. Current source is evidence, not
authority; existing rendering does not pass by incumbency.

Glyph, shape, tone, and text form one semantic claim and must agree with the approved state and
interaction. Glyph geometry alone does not declare a state. A benefit, capability, promise, or future outcome is neutral content, not a completed or failed state. Category and magnitude labels are not outcome states. A stable categorical palette is legal only when approved Grammar or application
authority defines it, the text label remains explicit, and the mapping is deterministic across every
consumer without asserting a transient outcome state.
