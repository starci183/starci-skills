# Media must perform an explicit user job

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.ui.media` |
| Operators | frontend direction, contract, implementation, review, and proof |
| Search tags | `media, image, AI generation, asset reuse, crop, alt, fallback, empty space` |
| Dependencies | `fe.ui`; approved content authority; routed Grammar |

Media is information architecture, not filler. First make approved content and ownership coherent,
then choose exactly one media decision: no media, reuse an approved asset, or generate a purpose-built
bitmap. Media is justified only when it materially improves orientation, recognition, explanation,
comparison, instruction, or approved emotional framing.

An AI-generated image may occupy an otherwise empty composition only when an explicit media contract
is frozen before generation. The contract declares user purpose, owning region and placement, source
or generation brief and forbidden claims, wide/intermediate/compact crop or contain behavior and
focal point, accessible alternative intent, and a loading/error/unavailable fallback.

Empty space alone is never a user purpose. Generated media must not hide weak composition, unedited
copy, missing approved content, an empty shell, or a wrong surface span. It must not compete with the
primary task or invent business authority. Prefer an approved reusable asset when it already performs
the role.

Every generated asset returns to the normal responsive render-review matrix. Generated text, fake
product UI, brand drift, implausible detail, awkward crop, inaccessible meaning, or a failed fallback
is a UI contradiction, not acceptable decoration.
