## Record

Unit proof checks the smallest executable owner without crossing a network, browser, real clock,
random source, or shared datastore boundary. Focused checks may support apply, but only the final
quality receipt after blind UI PASS gates frontend delivery; unit testing is not a visible stage or
repair loop. Select commands from the target manifest and inspect the matching StarCi FE or BE
reference only for test placement, naming, harness construction, and established fixture shape.

A valid unit batch covers the changed behavior, its meaningful boundary branch, and its failure path. Mock only an external boundary; do not mock the unit being proved. Freeze nondeterminism explicitly. A passing command with zero selected tests, skipped target tests, snapshots accepted without review, or suppressed failures is invalid.

Emit command, selected test files, result counts, coverage for the changed owner where the harness exposes it, and durable evidence. Missing harness authority or a failing assertion stops the chain; it never becomes an advisory warning.
