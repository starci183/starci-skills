# Offset Pop object: collections

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.grammar-offset-pop-object-collections` |
| Package | `@starci/grammar/offset-pop` |
| Operators | `fe/authority-reconcile` |
| Search tags | `collection, rows, subordinate contour, divider, state, list inside card` |
| Dependencies | `fe.grammar-common-case-collection-cardinality, fe.grammar-offset-pop-overview` |

The collection owner controls row anatomy, separators, state placement, row interaction, grouping, and overflow. Only one layer owns dominant offset depth.

- Use subordinate contour/divider treatment for rows inside a stronger outer surface.
- Keep identity, neutral state, and action in predictable positions.
- Avoid per-row rotation, shadows, or stickers in repeated operational data.
- Use one deliberate empty composition rather than a blank outlined box.
- Separate static and interactive rows unless the package declares a mixed variant.
- Simplify accents as item count grows.

Verify zero, one, many, long copy, mixed states, expanded, selected, partial, error, unbounded, and narrow screens. Reject card-per-row noise, scattered status stickers, unstable action placement, and dual depth owners.
