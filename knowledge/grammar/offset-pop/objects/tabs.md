# Offset Pop object: tabs

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.grammar-offset-pop-object-tabs` |
| Package | `@starci/grammar/offset-pop` |
| Operators | `grammar-convergence` |
| Search tags | `tabs, selected, underline gesture, contour, peer content, overflow` |
| Dependencies | `fe.grammar-offset-pop-overview, fe.grammar-common-states-accessibility` |

Tabs switch peer content in one task context. The selected tab may use the exact package fill, underline gesture, contour, or offset treatment.

- Keep labels unobscured and mutually exclusive.
- Unselected tabs remain clearly interactive without competing with selected.
- Focus, keyboard movement, activation, panel association, and overflow follow contract.
- Decorative underlines/circles cannot create a false second selection.
- Long labels reduce decorative gesture before losing readability.
- Unsaved-panel transitions remain application policy.

Reject sequential journey stages, independent routes, completion state, and unlimited tabs compressed into an unreadable strip.
