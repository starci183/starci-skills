# Offset Pop object: actions

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.grammar-offset-pop-object-actions` |
| Package | `@starci/grammar/offset-pop` |
| Operators | `fe/authority-reconcile` |
| Search tags | `button, primary, offset shadow, pressed, bright color, action group` |
| Dependencies | `fe.grammar-offset-pop-overview, fe.grammar-common-states-accessibility` |

Actions use the package's strong contour, role-bound fill, and offset-depth model while preserving conventional interaction clarity.

- One dominant action per decision region; bright secondary colors do not imply equal priority.
- Pressed behavior follows the declared offset transform and keeps the hit relationship stable.
- Focus remains visible against fill, contour, and shadow.
- Loading preserves context and blocks duplicate activation.
- Disabled and destructive remain distinguishable without relying on saturation alone.
- Long labels use declared wrap/size behavior; do not shrink below readability.
- Sticky mobile actions reduce offset depth when safe area or content visibility is threatened.

Verify hover, focus, pressed, loading, disabled, destructive, long label, icon-only, grouped, reduced motion, and mobile. Reject random fill colors, improvised transforms, and multiple maximum-emphasis actions.
