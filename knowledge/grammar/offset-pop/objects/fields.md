# Offset Pop object: fields

| Field | Value |
| --- | --- |
| Knowledge ID | `fe.grammar-offset-pop-object-fields` |
| Package | `@starci/grammar/offset-pop` |
| Operators | `grammar-convergence` |
| Search tags | `field, input, contour, label, validation, focus, dense form` |
| Dependencies | `fe.grammar-offset-pop-overview, fe.grammar-common-states-accessibility` |

Fields use a stable contour, readable interior, persistent label, and clearly separated support region. Decorative depth must never be confused with focus or invalid state.

- Keep label association and readable input geometry conventional.
- Combine validation text with the declared state marker; color or shadow alone is insufficient.
- Treat prefix, suffix, reveal, clear, and units as one field anatomy.
- Group fields only for a coherent relationship; do not outline every field group decoratively.
- In dense forms, remove accents before reducing spacing or text usability.
- Pending dependent fields retain geometry and explain why they cannot be used.

Verify autofill, focused, invalid, disabled, read-only, loading, long translated labels, zoom, keyboard, and mobile. Reject placeholder-only labels, decorative error stickers, and custom shadows that overwrite package state treatment.
