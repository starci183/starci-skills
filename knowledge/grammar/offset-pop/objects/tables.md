Offset Pop supports dense comparison only when expression does not reduce scanning speed.

- Use bold treatment for header or primary identity, not every cell.
- Keep comparable values aligned and row actions stable.
- Remove per-row rotation, overlap, and shadow as density grows.
- Bulk selection has one visible owner and scope.
- Sticky headers avoid offset layers that jitter or cover focus.
- Define loading, empty, error, partial, and stale separately.
- Responsive behavior uses declared scrolling, column priority, or alternate rows.

Reject color-per-column decoration, scattered action stickers, hidden selection scope, and mobile card conversion that destroys essential comparison.
