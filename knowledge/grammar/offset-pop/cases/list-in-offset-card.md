## Trigger

A strongly framed Offset Pop card contains a repeated list with its own row/state responsibility.

## Decision

The outer card owns dominant contour, offset depth, external label, summary, and block action. The inner collection uses subordinate border/dividers and no competing dominant shadow. Rows stay geometrically stable; repeated state marks occupy one position. Application code maps meaning to neutral states.

Use zero/one/many-specific row treatment, remove orphan dividers, and keep long copy clear of state/action columns.

## Responsive

Reduce or remove inner contour before losing grouping. Remove outer rotation if it causes clipping. Keep exactly one depth owner.

## Reject and proof

Reject card-per-row, two offset shadows, scattered stickers as status, business-named checks, or duplicate padding. Prove zero, one, many, mixed states, long content, focus, and mobile.
