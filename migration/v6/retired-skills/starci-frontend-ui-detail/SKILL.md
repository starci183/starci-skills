# StarCi frontend UI detail

Convert approved design into anatomy that implementation cannot reinterpret. Every surface has an owner, parent, order, merge rule, sticky/scroll behavior, state behavior, responsive behavior, and deterministic proof baseline. Every page, modal, drawer, popover, and inline decision binds to its trigger, container surface, dismissal, focus return, and mobile transformation. Breadcrumb, icon, and separator decisions are explicit.
