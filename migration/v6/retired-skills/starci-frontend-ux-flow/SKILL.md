# StarCi frontend UX flow

Turn one business outcome into a complete task flow before visual composition. Model only reachable transitions, but never omit client validation, business refusal, security/auth, expired/stale, concurrency, rate-limit, transport, realtime, interruption, escape, recovery, refresh, resume, or reversible navigation when applicable. Then compare page, modal, drawer, popover, and inline placement for every meaningful interaction; record one selection, rejected alternatives, behavior, focus return, and mobile transformation. New persistence or backend behavior remains a typed hypothesis and routes separately.
