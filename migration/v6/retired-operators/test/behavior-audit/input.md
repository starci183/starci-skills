# `test/behavior-audit` input

The context binds canonical backend `.worktrees/uat` authority, exact protocol and source references. The input freezes one flow, its separate predeclared cases, immutable revisions, visible Browser runtime, fixtures, and resources.

## Contract fields

- `context.featureIndexRef`: Canonical feature index under the verified backend Source .worktrees/uat authority.
- `context.reviewRef`: Canonical flow review under the verified backend Source .worktrees/uat authority.
- `context.siblingFlowRefs`: Exact sibling review references used only for coverage or merge comparison.
- `context.knowledgeRefs`: Exact protocol references resolved by default repository or file search.
- `context.sourceRefs`: Exact immutable product evidence references.
- `input.project`: Verified routed project identity.
- `input.flowId`: One audited flow identity.
- `input.caseRefs`: Predeclared cases in intended visible Browser order.
- `input.sourceRevision`: Immutable product source revision.
- `input.authorityRevision`: Immutable UAT authority revision.
- `input.runtimeRef`: Visible Browser runtime reference.
- `input.fixturePlanRef`: Fixture plan frozen before execution.
- `input.resourcePlanRef`: Resource plan frozen before execution.
