# interface.audit

Audits frozen primary interface surfaces on the exact attested route. Each selected viewport, color scheme and required state receives an actual screenshot, browser measurement record and verdict. Presentation, composition, responsive behavior, motion, accessibility, contrast, render truth and taste close independently by their bound rules.

The audit changes no source, runtime, data, account, direction or knowledge. A claim is not a measurement. A screenshot without its walk and measurement evidence is incomplete. Guarded routes are reached with credentials resolved by name and credential fields absent before capture. Journey-required states cannot be deferred to make an audit pass.

The six JSON modules define the shared envelopes, steps, machine checks, reviews and a two-round feedback loop. A done response includes `frontend-surface-audit`, `audit-captures`, `audit-screenshots` and `audit-verdicts`. Review results cite these actual outputs and name concrete capture, measurement, rule or calibration evidence.

Tests use synthetic local PNG and JSON files; they do not open a browser or mutate a product. Run `python .claude/operators/interface.audit/tests/run.py` after building the operator.
