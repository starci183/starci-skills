# fleet-wave-1 — first multi-agent kernel-coordinated wave

## Practiced

- ~27 concurrent `[Op]` lanes (devin + qwen) driven by one coordinator chat
  through Orca terminals + brief files + done markers
- Waves: tinkle-14..23 (distless migration), exup-1..8 (example upgrades),
  leftover tinkle-5,9..13 and hihi v7-9,v11-5
- `watchdog.sh` polling markers + git state every 5 min into
  `ex-testing/lint/FLEET-STATUS.md` + `watchdog.log`
- `kernel-watchdog` Orca automation (claude, cron */5) for judgment-level ticks
- Ownership boundaries per lane declared in briefs; cross-boundary needs go to
  report "needed elsewhere" instead of editing foreign files

## Observed

- `devin` agent child can die mid-run ("agent child exited: exit 0") leaving
  queued messages unprocessed — detected via `lastOutputAt` staleness (~77m idle)
- `qwen` TUI stalls on per-command permission prompts — needs "allow always"
  or a yolo-style flag at spawn; each stall cost ~50-60m of idle time
- `ACP_BACKEND=windsurf` env leak makes devin CLI take the wrong auth branch;
  must `Remove-Item Env:ACP_BACKEND` before spawning devin terminals
- `.claude` is a nested git repo — parent `git status` sees zero of its churn;
  any status/measurement must run inside `.claude` itself
- Stray files named `nul` (from `> nul` redirects) break `git add` entirely on
  Windows; PowerShell `\\?\` delete reports success but MSYS still sees them —
  `rm` in Git Bash works
- Husky hooks fail in agent shells (`eslint` not on PATH) — checkpoint commits
  need `--no-verify`
- Remote bootstrap (AGENTS/CLAUDE) had been rewritten upstream — merge took
  remote's newer text; `.dist` ref was already gone from it
- Marker+file-based coordination works: 44+ done markers landed across waves
  with zero coordinator round-trips per lane

## Derived

- **Lane health = output freshness**, not process liveness. `lastOutputAt` >30m
  on an agent lane = stalled → investigate, then respawn.
- **Spawn recipe matters**: devin needs `ACP_BACKEND` unset; qwen needs
  permission mode pre-answered or non-interactive flag.
- **Windows hazards belong in spawn tooling**: `nul` names, CRLF, PATH for
  hooks — dispatcher script should sanitize.
- **Two-tier verification**: deterministic board (markers, git state) +
  agentic tick (read reports, judge claims). Cheap truth + expensive judgment.
- Nested-repo boundary must be explicit in any path/git tooling.
